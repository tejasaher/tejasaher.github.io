💡 What I Do

  • Design and build scalable data platforms using cloud data warehouses like Snowflake and Amazon Redshift, enabling efficient data storage, processing, and analytics.
  • Architect and deploy data solutions on AWS using services such as S3, Lambda, and EKS, supporting robust and scalable microservice-based data workflows.
  • Develop and orchestrate end-to-end ELT pipelines using modern tools including DBT, Apache Airflow, Dagster, and Meltano.

  • Leverage Docker and Kubernetes to build scalable, containerized data workloads and streamline deployment processes.
  • Continuously explore modern technologies including AI-driven data applications and cloud-native tools to enhance data platform capabilities.
  • Focused on delivering high-quality, reliable data solutions that enable data-driven decision-making and business impact.
